# M3 — Перенос из doc-agent и формы документов. План реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** В Пылесосе есть свои копии модулей doc-agent (приведение файлов к страницам, клиент Ollama, распознавание, модель шаблона, проверки значений, запись Excel), приведённые к правилам кода, и новый экран «Формы документов»: пользователь загружает образец удостоверения или прав, отмечает мышью рамку карточки и места ФИО, ИИН, № документа, даты рождения — эти формы потом использует разбор (M4).

**Architecture:** Код копируется из `~/doc-agent` (коммит `46c6a3f`, П5) в `internal/llm`, `internal/ollama`, `internal/normalize`, `internal/tables`, `internal/validate`, `internal/recognize`, `internal/export` вместе с тестами doc-agent, которые становятся приёмкой переноса. Модель ChatGPT Web (`core`) не переносится: вместо `core.Request` — свой `llm.Request`, отвечает только Ollama (05-recognition-llm). Новое: `internal/docforms` (формы документов, П21: зоны принадлежат форме, а не шаблону; поля формы постоянные) — таблица `doc_forms`, сервис, экран и API; фронт экрана — рисование прямоугольников мышью (ввод пользователя, не логика).

**Tech Stack:** Go 1.26, `github.com/disintegration/imaging`, `github.com/klippa-app/go-pdfium` (WebAssembly, без CGO), `github.com/xuri/excelize/v2`, `golang.org/x/text`; React.

**Spec:** `docs/specs/2026-09-26-pylesos-design.md` — раздел 4 шаг 1 (документы), раздел 5 («Зоны на образце (П21)», «Excel»), раздел 6 (экран «Формы документов», «Настройки → Ollama»). Исследование — `docs/research/doc-agent.md`. Правила — `CLAUDE.md`, `.claude/rules/05-recognition-llm.md`, `07-clean-code.md`.

## Отличие этого плана от прежних (Ruling)

Задачи переноса (1–6) не приводят код целиком: код — это исходники doc-agent. Для каждого файла указано, откуда копировать и какие переделки обязательны. Приёмка переноса — **перенесённые тесты doc-agent** (сначала копируются тесты и падают — пакета нет; затем код; затем тесты зелёные) плюс проверки правил (длина функций/файлов, глобальные переменные, заголовок `// Файл:`). Новый код (задачи 7–9) расписан полностью, как в M1–M2.1.

## Global Constraints

- Всё из M1–M2.1 в силе: коммиты запрещены; файл ≤ 400 строк, функция ≤ 50; `// Файл:` первой строкой; глобальных переменных нет, кроме ошибок-меток и `//go:embed`; ошибки не игнорируются; тексты для пользователя — `internal/texts`.
- **Переделки при переносе (для всех файлов):** импорт `doc-agent/internal/...` → `pylesos/internal/...`; `core.Request` → `llm.Request`; `i18n.T(...)` → константы `texts`; `init()` с регистрацией ошибок — удалить; глобальные `regexp.MustCompile`, карты и срезы уровня пакета → функции (`func imageExts() map[string]bool {…}`) или поля структур; глобальное состояние (движок pdfium) → поля структуры с конструктором.
- Не переносить: `internal/core` (ChatGPT Web), `internal/i18n`, `internal/job` (обход папок), `internal/bench`, `internal/ui`, `export/markdown.go` (выгрузки текстом нет в спецификации), `tables/store.go` (шаблоны будут в базе — M5), обход папок `normalize.Walk/File`.
- Модель — только Ollama; по умолчанию `gemma4:e4b` (05-recognition-llm).
- Образец формы документа хранится в базе (нужен, чтобы показать зоны при правке). Реальные образцы — данные пользователя в его базе; в тесты — только сгенерированные картинки (П8).

## Review Focus

1. **PDF с паролем или битый файл** — понятная ошибка, программа не падает. Тест: Task 2, перенесённые `pdf_test.go` (`testdata/protected.pdf`).
2. **Ollama не запущена** — ответ модели — ошибка с понятным текстом, а не зависание. Тест: Task 1, перенесённый `TestRespondErrors`.
3. **Форма без рамки или без части полей** — сохраняется, разбор читает то, что отмечено; отметка вне картинки отклоняется. Тест: Task 7, `TestZoneValidation`.
4. **Две похожие формы** (лицевая и оборотная стороны) — выбирается более похожая, порог сходства соблюдается. Тест: Task 5, перенесённые тесты `zones_test.go` (`MatchForm`).
5. **Файл Excel открыт в Excel** — запись не падает, а даёт понятную ошибку/запасное имя. Тест: Task 6, перенесённый `TestWriteExcelFallsBackWhenFileIsLocked`.

```sql
-- Файл: internal/store/migrations/0004_doc_forms.sql
-- Формы документов (П21): образец, отпечаток, рамка карточки и зоны опознавательных полей.
CREATE TABLE doc_forms (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    name       TEXT    NOT NULL,

    zones      TEXT    NOT NULL DEFAULT '{}', -- JSON: поле → tables.Zone
    updated_at INTEGER NOT NULL
);
```
