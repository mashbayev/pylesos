# PROJECT_CONTEXT — Пылесос

## Что это
Локальная программа, которая собирает данные и выдаёт Excel-таблицу в формате, собранном пользователем
в конструкторе (П1, П4):
- **Telegram-группы** — люди (прежде всего водители из чёрных списков аренды авто), упоминания о них,
  документы (удостоверения, права), комментарии и переписка. Первая группа — «ЧС Астана» (`docs/research/telegram-chs-astana.md`).
- **Сайты объявлений** — olx.kz по поисковому запросу («Аренда авто», «Прокат авто», «Мебель даром»…), с телефонами продавцов.

## Для кого
Пользователь сам, на своём компьютере (П10). Не SaaS, не сервер, не многопользовательская система.

## Бизнес-флоу
1. **Сбор** — задание выгружает сообщения группы (аккаунт + бот) или объявления (браузер + JSON API OLX) в базу как есть.
2. **Разбор** — документы распознаются локальной моделью (Ollama), в сообщениях находятся люди, упоминания
   одного человека склеиваются (надёжные — автоматически, похожие — по подтверждению).
3. **Таблица** — шаблон конструктора (строка = человек / сообщение / объявление; колонки «Модель» или «Поле»)
   применяется к разобранным данным → Excel с подсветкой сомнительных ячеек.

## Стек
Go (бэкенд, вся логика) · React + Vite + TypeScript + Tailwind + TanStack Query (тонкий фронт) · SQLite (modernc, без CGO)
· `gotd/td` (Telegram MTProto) · Bot API · `chromedp` · Ollama (`gemma4:e4b`) · excelize.
