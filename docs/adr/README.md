# ADR — Architectural Decision Records

Здесь фиксируются архитектурные решения с объяснением «почему так, а не иначе». Каждое решение — отдельный файл
`ADR-NNN_короткое-название.md` (контекст → решение → причина → последствия).

Короткие обязательные формулировки решений пользователя живут в `.claude/rules/00-decisions.md` (П1…);
ADR пишется, когда за решением стоит выбор из вариантов, который важно не пересматривать заново.

## Статусы
- `Принято` — действующее решение
- `Отменено` — было, но изменено (указываем чем заменено)
- `Предложено` — на рассмотрении
