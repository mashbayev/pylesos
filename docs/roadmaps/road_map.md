# Пылесос — роадмап

Собирает данные из Telegram-групп и сайтов объявлений (olx.kz и подобных) и выдаёт Excel-таблицу,
формат которой задаётся в конструкторе внутри программы.

**Решения пользователя — `.claude/rules/00-decisions.md`, они обязательны для всех этапов.**

Статусы: 💬 обсуждается · 📝 спецификация · 🚧 в работе · ✅ готово

## Этапы

Спецификация: `docs/specs/2026-09-26-pylesos-design.md`. Порядок — П24: подряд M2 → M6; объём — MVP (П27).
