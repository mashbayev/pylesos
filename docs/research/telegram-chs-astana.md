# Telegram-группа «ЧС Астана» — форматы сообщений

Изучена 2026-09-26 через Telegram Web (только чтение). По П8 здесь только структура, без реальных данных.

Чёрный список водителей аренды авто, ~124 участника, посты от разных автопарков, группа ведётся примерно с 2026-09-17.

| Формат | Структура | Что нужно программе |
|---|---|---|
| Фото документа + подпись | удостоверение → «ФИО / В ЧС / долги по аренде / ущерб ТС на N тг» | ФИО из подписи и из документа, сверка |
| Только текст, одна строка | «ФИО ЧС! причина» | разбор имени и причины |
| Фото + подпись только с именем | «ФИО» | причины нет |
| Фото + подпись без имени | «ЧС. Бросил авто, аренду не платит…» | имя только из документа (распознавание) |
| Отдельная короткая реплика | «ФИО чс» после поста / ответ в ветке | прикрепить к тому же человеку |
| Запрос | «ФИО. Есть инфо?» + ответы | это проверка, не запись в ЧС; ответы — комментарии |
| Служебные | «X joined the group via invite link» | пропускать |

## Особенности

- Русский и казахский, в т.ч. казахский латиницей или без казахских букв.
- Имена в разном регистре и порядке (Фамилия Имя [Отчество]), опечатки → нужно нечёткое сравнение ФИО.
- Один человек может быть в нескольких постах от разных парков → склейка, все причины и авторы в одну строку.
- Типовые причины: долг по аренде, ущерб авто (с суммой), бросил авто, штрафы, нет прав, передача руля.

## Примеры колонок, которые пользователь может собрать в конструкторе

ФИО, ИИН (из документа), № удостоверения/прав, причины, сумма ущерба/долга, кто добавил, дата,
ссылка на сообщение, комментарии, фото.
