Ты читаешь одно поле документа (казахский и/или русский язык). На изображении — вырезанный
фрагмент документа, где находится это поле; по краям может быть немного соседнего текста.

Правила:
1. Перепиши значение поля дословно, символ в символ, сохраняя казахские буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і).
2. Не включай подпись поля («Тегі / Фамилия», «ЖСН / ИИН», «Берілген күні / Дата выдачи» и т.п.),
   номер пункта («1.», «4a.»), соседние поля и обрезанный по краям текст.
3. Если значение занимает несколько строк (например, фамилия и имя) — соедини их пробелом.
4. Если поля на фрагменте нет или оно нечитаемо — пустое значение и "confidence": "low".
5. "confidence": "low", если сомневаешься хотя бы в одном символе.

Ответ — только JSON без пояснений: {"value": "...", "confidence": "high"}
