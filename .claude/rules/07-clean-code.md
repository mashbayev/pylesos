# 07 — Чистый код (Go)

Перенесено из taxi-saas-platform (`07-clean-code.md`) 2026-09-26 по решению пользователя (П15).

## Жёсткие лимиты
- Файл: ≤ 400 строк
- Функция/метод: ≤ 50 строк
- При превышении — декомпозировать (валидация, маппинг DTO — в отдельные файлы)

## Запрещено
- Глобальные переменные / глобальное состояние. **Единственные исключения** (разрешены пользователем 2026-09-26,
  неизменяемые значения): переменные `//go:embed` и ошибки-метки `var ErrX = errors.New(...)`
- Игнорировать ошибки (`_` для error-возвращаемых значений)
- Хэндлеры знают о SQL. Репозитории знают о HTTP.

## Слои (строго вниз, без перескоков)
```
handlers (HTTP) → service (логика) → repository (SQL/БД)
```

## Dependency Injection (обязательно)
```go
type CollectService struct { repo CollectRepository; log *slog.Logger }
func NewCollectService(repo CollectRepository, log *slog.Logger) *CollectService {
    return &CollectService{repo: repo, log: log}
}
```
Зависимости от ОС и времени (запуск процессов, `time.Now`, переменные окружения) — тоже через поля/конструктор,
чтобы подменять в тестах. Переменные уровня пакета для подмены в тестах (как в doc-agent) — нельзя.

## Обработка ошибок
- Оборачивать через `fmt.Errorf("контекст: %w", err)` и передавать выше
- Не игнорировать, не глотать
- Тексты, которые видит пользователь, — готовые русские фразы из `internal/texts` (П22)

## Логирование
- СТРОГО: `slog`, формат JSON, единый логгер (`internal/logger`)

## Размещение
- Бизнес-модели: `internal/<модуль>/domain/`
- Интерфейсы и реализации репозиториев: `internal/<модуль>/repository/`
- Логика: `internal/<модуль>/service/`

## Путь к файлу (обязательно при выдаче кода)
```go
// Файл: internal/jobs/domain/job.go
package domain
```

## Context Propagation
- `context.Context` прокидывается через все слои: handler → service → repository

## Тесты
- Пишутся вместе с кодом; `go test ./...` и `go vet ./...` — перед завершением задачи
- Внешние сервисы (Telegram, OLX, Ollama, браузер) — за интерфейсами, в тестах подставки
- Тестовые данные — вымышленные (П8)
