# 05 — Распознавание и модель (Ollama)

Решения: П5, П12, П21. Подробно — спецификация, разделы 4–5; что копируем — `docs/research/doc-agent.md`.

## Жёсткие правила
- Модель — локальная, через Ollama (`gemma4:e4b` по умолчанию). Облачных моделей нет.
- Код распознавания, проверок и Excel — копия doc-agent (коммит `46c6a3f`), приведённая к `07-clean-code.md`.
- Ответы модели — строго по JSON-схеме; не тот JSON → один повтор → «не разобрано: ошибка модели», работа идёт дальше.
- Обращения к модели — строго по одному (одна видеокарта).
- Распознанный текст документа хранится; файл документа удаляется сразу после распознавания (П12).
- Зоны на образце принадлежат **формам документов**, не шаблону таблицы (П21).
- Ячейки таблицы кэшируются по колонке и хэшу входных текстов (`cell_cache`) — не гонять модель повторно.
- Ollama не запущена → задания разбора ждут («запустите Ollama»), сбор продолжается.

## Грабли
- Перенесённые тесты doc-agent — приёмка переноса; реальные ФИО из групп в них и в промптах заменять вымышленными (П8).
- Движок pdfium запускается дорого (под -race ~20 с) — один `normalize.Normalizer` на программу и один на тест с подтестами.
- Нечитаемая страница/зона в `recognize` — «зон нет», поле читает модель по всей странице (не ошибка разбора).
- `ollama.VisionModels` с истёкшим сроком возвращает ошибку, а не пустой список (иначе «модель не установлена»).
