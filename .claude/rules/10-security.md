# 10 — Безопасность

Адаптировано из taxi-saas-platform (`10-security.md`) под локальную программу (П10). JWT/RBAC/rate-limit — неприменимы.

## Локальный сервер
- Слушает только `127.0.0.1` (порт случайный)
- Все `/api/*` — только с токеном запуска (заголовок `X-Pylesos-Token` или `?t=` для SSE); токен — в адресе окна
- `Host` — только `127.0.0.1:<порт>` или `localhost:<порт>` (защита от DNS rebinding)
- `POST` — только `Content-Type: application/json`
- Образец — `guard` из doc-agent (`internal/ui/server.go`)

## Секреты
- Сессия Telegram, токен бота — в `secrets`, AES-256-GCM; ключ — файл в папке данных с правами `0600`
- Cookies OLX — только в профиле Chromium в папке данных, не в базе
- Папка данных — права `0700`
- Все учётные данные вводит пользователь сам (П19); встроенных ключей нет
- НИКОГДА не коммитить: сессии, токены, cookies, файл ключа, базу

## Персональные данные
- Реальные имена, ИИН, фото из групп — не в репозиторий, не в документацию, не в тесты (П8)
- Фото документов удаляются после распознавания (П12)

## Сайты
- Никакого обхода защиты от ботов и капчи (П11, П13)
