# 03 — Telegram

Решения: П6, П7, П17, П18, П19, П20. Подробно — спецификация, разделы 3–4; форматы сообщений — `docs/research/telegram-chs-astana.md`.

## Жёсткие правила
- История и догрузка — аккаунт пользователя через `gotd/td` (MTProto). Новые сообщения — бот (Bot API, long polling).
- `api_id`/`api_hash`, номер, код, облачный пароль, токен бота вводит пользователь в окне (П19).
- Уникальный ключ сообщения — группа + номер: аккаунт и бот не дублируют друг друга.
- Медиа на сборе не скачиваются (только ссылка); скачивание → распознавание → удаление файла — на разборе (П12).
- FLOOD_WAIT — ждать указанное время, показывать в статусе задания; не обходить.
- Склейка людей (П17): автоматически — ИИН или точное нормализованное ФИО (и только если такой человек один);
  похожие — только через подтверждение. **При сомнении не склеивать.**
- Разбор не извлекает колонки шаблона — только кто упомянут и роль (запись / запрос / комментарий).

## Грабли
- Bot API хранит непрочитанные обновления ~24 часа — догрузку пропусков делает аккаунт, не бот.
- Бот не видит удаления; правки старых сообщений видит только бот, пока программа запущена.
- Номера сообщений бота и MTProto совпадают только в супергруппах; `chat_id` бота = `-100` + id канала.
- Отметка «аккаунтом загружено до №N» — `tg_sync_state.synced_top`, НЕ `MAX(msg_id)`: бот и оборванный проход сдвигают максимум, а дыра остаётся навсегда.
- Порция истории может целиком состоять из служебных сообщений — конец истории только при пустом ответе (`Page.Lowest == 0`).
- gotd: неверный пароль — `auth.ErrPasswordInvalid` (не tgerr), номер без аккаунта — `*auth.SignUpRequired`; подключение без сети переподключается бесконечно — ждать с таймаутом, не под мьютексом.
- Бот: только супергруппы-источники; offset сдвигается после записи порции; новый токен сбрасывает offset.
- `author_id` канала у бота приходит как `-100…` — приводить к id канала (`channelIDOf`), как у аккаунта.
- События SSE несут список экранов (`events.Jobs()`, `events.Bot()`) — какие экраны перечитать, решает бэкенд.
