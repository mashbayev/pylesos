# 04 — Сайты объявлений (OLX и др.)

Решения: П11, П13. Подробно — спецификация, раздел 3; факты — `docs/research/olx.md`.

## Жёсткие правила
- Только через управляемый браузер (`chromedp`, свой профиль в папке данных) и JSON API сайта из контекста его страницы.
- **Запрещено:** прямые HTTP-запросы в обход браузера, подмена отпечатков, прокси, обход капчи.
- Капча/блокировка → задание `waiting_user`, окно браузера на передний план; пользователь проходит проверку сам.
- Телефон: сначала из текста объявления; по кнопке — только в режиме задания «все» или для отмеченных; пауза из настроек.
- Площадка = реализация интерфейса `sites` (добавление новой не меняет ядро).

## Грабли
- olx.kz отдаёт 403 (CloudFront) на любые запросы не из браузера — даже `robots.txt`.
- `/api/v1/offers/` отдаёт не больше 1000 объявлений на запрос — больше только сужением фильтров.
- Телефона в выдаче нет, только `contact.phone = true`; номер — отдельный запрос с входом в аккаунт.
