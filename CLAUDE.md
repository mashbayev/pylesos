# Пылесос — Agent Navigator

Локальная программа: сбор данных из Telegram-групп и сайтов объявлений (olx.kz) в Excel по шаблону из конструктора.
Backend: Go 1.26. DB: SQLite (modernc, без CGO). Frontend: React + Vite + TypeScript + Tailwind (тонкий клиент).

---

## 🛑 ЖЁСТКИЕ ПРАВИЛА (всегда в контексте, без исключений)

1. **Решения пользователя неприкосновенны:** `.claude/rules/00-decisions.md` (П1…). Противоречие правилу —
   остановиться и спросить. Правило меняет только пользователь.
2. **Каждое решение из обсуждения — сразу в документацию, в том же ответе (П9):** решение → `00-decisions.md`;
   факты об источниках и чужом коде → `docs/research/`; этапы и открытые вопросы → `docs/roadmaps/road_map.md`.
3. **ТОНКИЙ КЛИЕНТ — абсолютный запрет логики на фронте (П3):** вычисления, проверки, статусы, тексты — в Go.
   Нужна логика → сначала Go-endpoint с готовым полем → фронт читает и рендерит. Подробно — `09-frontend.md`.
4. **ORM ЗАПРЕЩЁН:** только `sqlx` поверх SQLite.
5. **Размер кода:** файл ≤ 400 строк, функция/метод ≤ 50 строк.
6. **Путь к файлу:** при выдаче кода первой строкой — комментарий `// Файл: path/to/file.go`.
7. **GIT-КОММИТЫ ЗАПРЕЩЕНЫ:** не делать `git commit`, не предлагать, не спрашивать. Коммит и push — только по прямой просьбе пользователя (П31).
8. **`go vet ./...` обязателен** после изменений Go (`go build` не проверяет `*_test.go`).
9. **Сборка после изменений:** задача выполнена, когда программа собирается целиком (`scripts/build.sh`: фронт + проверки + бинарник).
10. **Не тестировать без явного указания:** сверх тестов, которые пишутся вместе с кодом, — никаких ручных прогонов
    с реальными Telegram/OLX/браузером по своей инициативе.
11. **Не строй догадки:** не хватает файла или информации — остановись и спроси.
12. **Только текущий этап** (`08-development-stages.md`): код будущих этапов «заранее» не пишется.
13. **Персональные данные (П8):** реальные имена, ИИН, фото из групп — не в код, не в тесты, не в документы.
14. **Язык общения — русский:** пояснения, статусы, отчёты. Комментарии в коде — тоже на русском.
15. **База знаний:** решения обсуждения — сразу (правило 2). Остальные правки `docs/` и `.claude/rules/` по итогам
    работы с кодом — **только после вопроса пользователю** «Нужно ли обновить базу знаний (…)?».
